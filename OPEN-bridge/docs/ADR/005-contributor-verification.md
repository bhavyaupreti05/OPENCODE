# ADR 005: Contributor Verification Model

## Status
Accepted

## Context
Verified contributors can publish content. Verification must be meaningful but achievable for real contributors.

## Decision
- Verification through contribution proof submission
- Manual review by existing verified contributors/admins
- Proof types: PR URLs, contribution links
- Status: pending → verified/rejected
- Verified contributors get publishing rights

## Consequences
- Positive: Ensures quality content
- Positive: Builds community of real contributors
- Negative: Manual review overhead
- Negative: Potential delays in verification

## Alternatives Considered
- Automated verification: Rejected - too complex/risky
- No verification: Rejected - allows low-quality content

## Compliance
Supports bridge to real contribution without faking verification.
