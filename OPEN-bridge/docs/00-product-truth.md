# Product Truth

This product is NOT:

- just a course website
- just a LeetCode clone
- just an open-source issue board
- just a docs website

This product IS:

A guided bridge that takes beginners and confused college students from:

confusion -> confidence -> real-world readiness -> open-source contribution

The real problem being solved:

- beginners are scared of open source
- they do not know what to pick
- they do not understand messy repositories
- they lack confidence
- they need structured practice before real contribution

The platform must therefore help users:

- choose their tech stack
- choose a skill/domain
- choose a difficulty
- receive structured learning paths from basic to advanced
- solve practice problems
- fix simulated real-world bugs
- read open-source guidance/documentation based on their selected stack and level
- get guided exposure to real contribution paths
- eventually show proof of real contribution

The system must preserve this exact learning journey:

1. Learn
2. Practice
3. Simulate
4. Understand how real contribution works
5. Move toward actual contribution

Do not reduce this idea into a generic "problem solving platform".
Do not lose the beginner-confidence-building angle.
Do not hallucinate missing features.
