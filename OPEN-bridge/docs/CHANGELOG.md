- Initial project structure setup with MERN stack compliance
- Modular architecture with separate frontend and backend modules
- Documentation framework with product truth, system map, section docs, and ADRs
- Core domain model definitions for all entities
- Public API contract documentation for all route groups
- Development tooling setup (ESLint, Prettier, Jest, package.json files)

- Module README template
- Architecture Decision Records for key design choices
- Backend authentication and onboarding modules implemented
- Frontend signup, login, onboarding, and dashboard UI scaffolding added
- API client wrapper created for authenticated requests
- Seed script extended with stacks, skills, and difficulty level data
